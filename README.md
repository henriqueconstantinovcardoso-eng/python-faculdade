# Python - Projetos da Faculdade

Repositório com exercícios e projetos práticos desenvolvidos em Python durante o curso de Tecnologia em Análise e Desenvolvimento de Sistemas (IFSP São Carlos).

## Arquivos e Conteúdos

- **agenda_telefonica.py**: Implementação de uma agenda telefônica para gerenciamento de contatos com operações de busca e armazenamento.
- **anagramas_palindromos.py**: Algoritmos para detecção e verificação de anagramas e palavras palíndromas.
- **filmes_estatisticas.py**: Processamento e análise estatística de dados sobre catálogos ou notas de filmes.
- **funcoes_matematicas.py**: Módulo com implementações de funções e cálculos matemáticos essenciais.
- **operacoes_matriciais.py**: Resolução de operações com matrizes e manipulação de listas multidimensionais.
